# 🍔 Khadija's Food - Restaurant Web App

Khadija's Food is a modern and responsive restaurant website built using **HTML, CSS, and JavaScript**.  
It provides a clean UI for browsing food items, adding to cart, managing favorites, and viewing total bill.

---

## 🚀 Features

- 🔐 Email Login UI (Frontend)
- 🏠 Home Page with Banner
- 🍔 15+ Food Items Grid (Responsive Cards)
- 🛒 Add to Cart System
- 💖 Favorites / Wishlist System
- 💰 Total Bill Calculator
- 📄 About Section Toggle
- 📱 Fully Responsive Design
- 🎨 Hover Effects & Smooth UI Animations
- 🔗 Footer with Social Links

---


## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Vanilla JS)
